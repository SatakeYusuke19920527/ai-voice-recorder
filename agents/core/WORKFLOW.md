# WORKFLOW.md

## Standard Workflow
1. Clarify request and impacted modules.
2. Inspect current implementation and constraints.
3. Implement minimal-risk change.
4. Validate by build/test.
5. Report results, risks, and next steps.

## Branch/Change Practice
- Keep changes focused.
- Prefer small, reviewable diffs.
- Avoid unrelated refactors unless explicitly requested.
